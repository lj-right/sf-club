# 编程面试题精讲

> 本文档收录高频编程面试题，按数据结构与算法分类。每题包含题目、思路、参考代码（Java）、复杂度与易错点，可用于刷题助手的出题、分步讲解与考点总结。

## 一、数组与双指针

### 1. 两数之和（LeetCode 1）—— 考点：哈希表

- 题目：给定整数数组 nums 和目标值 target，返回两数之和等于 target 的下标。
- 思路：暴力枚举 O(n^2)；最优用哈希表一次遍历，边遍历边查 target - nums[i] 是否在表中。
- 参考代码：
  ```java
  public int[] twoSum(int[] nums, int target) {
      Map<Integer, Integer> map = new HashMap<>();
      for (int i = 0; i < nums.length; i++) {
          int need = target - nums[i];
          if (map.containsKey(need)) return new int[]{map.get(need), i};
          map.put(nums[i], i);
      }
      return new int[0];
  }
  ```
- 复杂度：时间 O(n)，空间 O(n)。
- 易错点：返回的是下标不能排序；先查再存避免使用同一元素；注意题目是否保证有解。

### 2. 三数之和（LeetCode 15）—— 考点：排序 + 双指针

- 题目：找出数组中所有和为 0 且不重复的三元组。
- 思路：先排序，固定第一个数后用双指针在剩余区间找两数之和。
- 参考代码：
  ```java
  public List<List<Integer>> threeSum(int[] nums) {
      Arrays.sort(nums);
      List<List<Integer>> res = new ArrayList<>();
      for (int i = 0; i < nums.length - 2; i++) {
          if (nums[i] > 0) break;
          if (i > 0 && nums[i] == nums[i - 1]) continue;
          int l = i + 1, r = nums.length - 1;
          while (l < r) {
              int s = nums[i] + nums[l] + nums[r];
              if (s < 0) l++;
              else if (s > 0) r--;
              else {
                  res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                  while (l < r && nums[l] == nums[l + 1]) l++;
                  while (l < r && nums[r] == nums[r - 1]) r--;
                  l++; r--;
              }
          }
      }
      return res;
  }
  ```
- 复杂度：时间 O(n^2)，空间 O(log n)（排序栈）。
- 易错点：去重需在找到答案后跳过相邻重复值；固定数去重用 nums[i]==nums[i-1] 判断；nums[i] > 0 可提前剪枝。

### 3. 盛最多水的容器（LeetCode 11）—— 考点：双指针 / 贪心

- 题目：数组中每个元素表示高度，求两条竖线与 x 轴构成容器能容纳最多水的面积。
- 思路：左右双指针，每次移动较短的一边，因为移动较长的一边不可能得到更大面积。
- 参考代码：
  ```java
  public int maxArea(int[] h) {
      int l = 0, r = h.length - 1, ans = 0;
      while (l < r) {
          ans = Math.max(ans, Math.min(h[l], h[r]) * (r - l));
          if (h[l] < h[r]) l++; else r--;
      }
      return ans;
  }
  ```
- 复杂度：时间 O(n)，空间 O(1)。
- 易错点：面积由较短边和距离共同决定；不要写成两边都往中间缩。

## 二、链表

### 4. 反转链表（LeetCode 206）—— 考点：指针操作

- 题目：反转单链表。
- 思路：迭代法用三个指针 prev、curr、next 逐个翻转；也可递归。
- 参考代码：
  ```java
  public ListNode reverseList(ListNode head) {
      ListNode prev = null, curr = head;
      while (curr != null) {
          ListNode next = curr.next;
          curr.next = prev;
          prev = curr;
          curr = next;
      }
      return prev;
  }
  ```
- 复杂度：时间 O(n)，空间 O(1)。
- 易错点：先保存 next 再改 curr.next；最后返回 prev 而非 head。

### 5. 环形链表 II（LeetCode 142）—— 考点：快慢指针

- 题目：返回链表环的入口节点，无环返回 null。
- 思路：快慢指针判断有环，相遇后从 head 和相遇点同时走，再次相遇即为入口。
- 参考代码：
  ```java
  public ListNode detectCycle(ListNode head) {
      ListNode slow = head, fast = head;
      while (fast != null && fast.next != null) {
          slow = slow.next; fast = fast.next.next;
          if (slow == fast) {
              ListNode p = head;
              while (p != slow) { p = p.next; slow = slow.next; }
              return p;
          }
      }
      return null;
  }
  ```
- 复杂度：时间 O(n)，空间 O(1)。
- 易错点：需要先让快慢都从 head 出发再判断；数学证明 a = c - b 是关键。

### 6. 合并两个有序链表（LeetCode 21）—— 考点：伪头节点

- 题目：将两个升序链表合并为一个新的升序链表。
- 思路：用哑节点 dummy 简化头节点处理，比较后拼接较小值。
- 参考代码：
  ```java
  public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
      ListNode dummy = new ListNode(-1), tail = dummy;
      while (l1 != null && l2 != null) {
          if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
          else { tail.next = l2; l2 = l2.next; }
          tail = tail.next;
      }
      tail.next = (l1 != null) ? l1 : l2;
      return dummy.next;
  }
  ```
- 复杂度：时间 O(m+n)，空间 O(1)。
- 易错点：记得拼接剩余链表；返回 dummy.next 而不是 dummy。

## 三、栈与队列

### 7. 有效括号（LeetCode 20）—— 考点：栈

- 题目：判断仅含 ()[]{} 的字符串是否有效闭合。
- 思路：遇左括号入栈，遇右括号检查栈顶是否匹配，最后栈需为空。
- 参考代码：
  ```java
  public boolean isValid(String s) {
      Deque<Character> st = new ArrayDeque<>();
      for (char c : s.toCharArray()) {
          if (c == '(') st.push(')');
          else if (c == '[') st.push(']');
          else if (c == '{') st.push('}');
          else if (st.isEmpty() || st.pop() != c) return false;
      }
      return st.isEmpty();
  }
  ```
- 复杂度：时间 O(n)，空间 O(n)。
- 易错点：巧妙做法是左括号直接入栈对应的右括号；最后必须检查栈空。

### 8. 最小栈（LeetCode 155）—— 考点：辅助栈

- 题目：设计支持 push、pop、top 与获取最小值的栈，各操作 O(1)。
- 思路：维护一个辅助栈同步记录当前最小值。
- 参考代码：
  ```java
  Deque<Integer> data = new ArrayDeque<>(), min = new ArrayDeque<>();
  public void push(int x) {
      data.push(x);
      min.push(min.isEmpty() ? x : Math.min(min.peek(), x));
  }
  public int getMin() { return min.peek(); }
  ```
- 复杂度：所有操作 O(1)。
- 易错点：最小值栈要与数据栈同步 push/pop；也可只在新值 <= 当前最小值时入栈以省空间。

## 四、二叉树

### 9. 二叉树的中序遍历（LeetCode 94）—— 考点：迭代遍历

- 题目：返回二叉树的中序遍历结果。
- 思路：递归简单；迭代用栈一路向左压栈，弹出访问后再转向右子树。
- 参考代码：
  ```java
  public List<Integer> inorderTraversal(TreeNode root) {
      List<Integer> res = new ArrayList<>();
      Deque<TreeNode> st = new ArrayDeque<>();
      while (root != null || !st.isEmpty()) {
          while (root != null) { st.push(root); root = root.left; }
          root = st.pop();
          res.add(root.val);
          root = root.right;
      }
      return res;
  }
  ```
- 复杂度：时间 O(n)，空间 O(h)。
- 易错点：外层循环条件是 root 非空或栈非空；转向右子树后继续内层左链压栈。

### 10. 二叉树的层序遍历（LeetCode 102）—— 考点：BFS

- 题目：自顶而上逐层返回节点值。
- 思路：用队列 BFS，每一层处理前先记录当前队列大小。
- 参考代码：
  ```java
  public List<List<Integer>> levelOrder(TreeNode root) {
      List<List<Integer>> res = new ArrayList<>();
      if (root == null) return res;
      Queue<TreeNode> q = new ArrayDeque<>();
      q.offer(root);
      while (!q.isEmpty()) {
          int size = q.size();
          List<Integer> level = new ArrayList<>();
          for (int i = 0; i < size; i++) {
              TreeNode n = q.poll();
              level.add(n.val);
              if (n.left != null) q.offer(n.left);
              if (n.right != null) q.offer(n.right);
          }
          res.add(level);
      }
      return res;
  }
  ```
- 复杂度：时间 O(n)，空间 O(n)。
- 易错点：必须先取 size 再循环，否则队列会动态变化；空树直接返回。

### 11. 二叉树的最大深度（LeetCode 104）—— 考点：递归 / DFS

- 题目：求二叉树最大深度。
- 思路：递归返回左右子树最大深度加 1。
- 参考代码：
  ```java
  public int maxDepth(TreeNode root) {
      if (root == null) return 0;
      return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
  }
  ```
- 复杂度：时间 O(n)，空间 O(h)。
- 易错点：空节点返回 0；深度是节点数而非边数。

## 五、图

### 12. 岛屿数量（LeetCode 200）—— 考点：DFS / BFS / 并查集

- 题目：'1' 为陆地、'0' 为水，求岛屿数量。
- 思路：遍历网格，遇到 '1' 计数 +1 并 DFS 感染（置 '0'）整个连通块。
- 参考代码：
  ```java
  public int numIslands(char[][] grid) {
      int cnt = 0;
      for (int i = 0; i < grid.length; i++)
          for (int j = 0; j < grid[0].length; j++)
              if (grid[i][j] == '1') { cnt++; dfs(grid, i, j); }
      return cnt;
  }
  void dfs(char[][] g, int i, int j) {
      if (i < 0 || j < 0 || i >= g.length || j >= g[0].length || g[i][j] != '1') return;
      g[i][j] = '0';
      dfs(g, i + 1, j); dfs(g, i - 1, j); dfs(g, i, j + 1); dfs(g, i, j - 1);
  }
  ```
- 复杂度：时间 O(mn)，空间 O(mn) 递归栈。
- 易错点：边界与水一起判断；感染后置 '0' 防止重复访问；也可用 BFS 避免栈溢出。

## 六、二分查找

### 13. 在排序数组中查找元素的第一个和最后一个位置（LeetCode 34）—— 考点：二分边界

- 题目：在有序数组中找目标值的起止下标，不存在返回 [-1,-1]。
- 思路：写两个二分，分别找左边界（首个 >= target）和右边界（首个 > target 再 -1）。
- 参考代码：
  ```java
  public int[] searchRange(int[] nums, int target) {
      int l = lower(nums, target), r = lower(nums, target + 1) - 1;
      if (l < nums.length && nums[l] == target) return new int[]{l, r};
      return new int[]{-1, -1};
  }
  int lower(int[] nums, int t) {
      int l = 0, r = nums.length;
      while (l < r) { int m = (l + r) >>> 1; if (nums[m] < t) l = m + 1; else r = m; }
      return l;
  }
  ```
- 复杂度：时间 O(log n)，空间 O(1)。
- 易错点：用 lower_bound 模板统一处理；返回前要校验下标有效性；mid 用无符号右移避免溢出。

## 七、动态规划

### 14. 最长递增子序列（LeetCode 300）—— 考点：DP / 二分

- 题目：求最长严格递增子序列长度。
- 思路：O(n^2) DP：dp[i] 为以 nums[i] 结尾的最长长度；可优化为 O(n log n) 用 patience 排序。
- 参考代码（贪心 + 二分）：
  ```java
  public int lengthOfLIS(int[] nums) {
      int[] tails = new int[nums.length]; int size = 0;
      for (int x : nums) {
          int i = Arrays.binarySearch(tails, 0, size, x);
          if (i < 0) i = -(i + 1);
          tails[i] = x;
          if (i == size) size++;
      }
      return size;
  }
  ```
- 复杂度：时间 O(n log n)，空间 O(n)。
- 易错点：tails 数组存的是各长度的最小尾元素；binarySearch 找插入点而非精确匹配；严格递增用 lower_bound。

### 15. 最长公共子序列（LeetCode 1143）—— 考点：二维 DP

- 题目：求两个字符串的最长公共子序列长度。
- 思路：dp[i][j] 表示 text1 前 i 个与 text2 前 j 个的 LCS；字符相等则 dp[i-1][j-1]+1，否则取两侧较大值。
- 参考代码：
  ```java
  public int longestCommonSubsequence(String a, String b) {
      int m = a.length(), n = b.length();
      int[][] dp = new int[m + 1][n + 1];
      for (int i = 1; i <= m; i++)
          for (int j = 1; j <= n; j++)
              dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                  ? dp[i - 1][j - 1] + 1
                  : Math.max(dp[i - 1][j], dp[i][j - 1]);
      return dp[m][n];
  }
  ```
- 复杂度：时间 O(mn)，空间 O(mn)，可滚动数组优化到 O(min(m,n))。
- 易错点：状态定义是"前 i 个"而非下标 i；初始化第 0 行列默认 0。

### 16. 打家劫舍（LeetCode 198）—— 考点：线性 DP

- 题目：不能偷相邻两间房，求能偷到的最大金额。
- 思路：dp[i] = max(dp[i-1], dp[i-2] + nums[i])，可滚动两个变量。
- 参考代码：
  ```java
  public int rob(int[] nums) {
      int prev2 = 0, prev1 = 0;
      for (int x : nums) {
          int cur = Math.max(prev1, prev2 + x);
          prev2 = prev1; prev1 = cur;
      }
      return prev1;
  }
  ```
- 复杂度：时间 O(n)，空间 O(1)。
- 易错点：初始 prev2、prev1 均为 0；理解 dp[i-1] 表示不偷当前。

## 八、回溯

### 17. 全排列（LeetCode 46）—— 考点：回溯

- 题目：返回不含重复数字数组的所有全排列。
- 思路：回溯，用 visited 数组标记已用元素，路径填满后收集。
- 参考代码：
  ```java
  public List<List<Integer>> permute(int[] nums) {
      List<List<Integer>> res = new ArrayList<>();
      backtrack(nums, new boolean[nums.length], new ArrayList<>(), res);
      return res;
  }
  void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
      if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
      for (int i = 0; i < nums.length; i++) {
          if (used[i]) continue;
          used[i] = true; path.add(nums[i]);
          backtrack(nums, used, path, res);
          path.remove(path.size() - 1); used[i] = false;
      }
  }
  ```
- 复杂度：时间 O(n * n!)，空间 O(n)。
- 易错点：收集结果时必须 new 一份 path；回溯后要撤销选择（path 与 used 都还原）。

## 九、贪心

### 18. 跳跃游戏 II（LeetCode 45）—— 考点：贪心

- 题目：每步可跳 nums[i] 步，求跳到末尾的最少步数。
- 思路：维护当前一跳能到达的最远边界 end 与下一跳能到的最远 maxFar，到达 end 时步数 +1 并更新 end。
- 参考代码：
  ```java
  public int jump(int[] nums) {
      int steps = 0, end = 0, maxFar = 0;
      for (int i = 0; i < nums.length - 1; i++) {
          maxFar = Math.max(maxFar, i + nums[i]);
          if (i == end) { steps++; end = maxFar; }
      }
      return steps;
  }
  ```
- 复杂度：时间 O(n)，空间 O(1)。
- 易错点：只遍历到 n-2（最后一步无需再跳）；可达性题目（跳跃游戏 I）用类似维护 maxFar 判断即可。

## 十、字符串

### 19. 最长回文子串（LeetCode 5）—— 考点：中心扩展

- 题目：返回字符串中最长回文子串。
- 思路：以每个位置（及每两个位置之间）为中心向两边扩展，记录最长。
- 参考代码：
  ```java
  public String longestPalindrome(String s) {
      int start = 0, maxLen = 1;
      for (int i = 0; i < s.length(); i++) {
          int l = i - 1, r = i + 1;
          while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
          if (r - l - 1 > maxLen) { maxLen = r - l - 1; start = l + 1; }
      }
      return s.substring(start, start + maxLen);
  }
  ```
- 复杂度：时间 O(n^2)，空间 O(1)。
- 易错点：奇偶长度中心都要处理（也可统一写法）；记录长度后用 substring 取串。

## 十一、滑动窗口

### 20. 无重复字符的最长子串（LeetCode 3）—— 考点：滑动窗口

- 题目：求不含重复字符的最长子串长度。
- 思路：维护窗口 [l, r]，用哈希表记录字符上次出现位置，遇重复则收缩左边界。
- 参考代码：
  ```java
  public int lengthOfLongestSubstring(String s) {
      Map<Character, Integer> last = new HashMap<>();
      int l = 0, ans = 0;
      for (int r = 0; r < s.length(); r++) {
          char c = s.charAt(r);
          if (last.containsKey(c)) l = Math.max(l, last.get(c) + 1);
          last.put(c, r);
          ans = Math.max(ans, r - l + 1);
      }
      return ans;
  }
  ```
- 复杂度：时间 O(n)，空间 O(min(m, n))（字符集大小）。
- 易错点：收缩左边界时取 max 避免回退；用哈希存下标而非计数更高效。

## 十二、解题通用模板

- 双指针（有序数组去重 / 两数之和类）：先排序，再用左右指针根据和与目标的关系移动。
- 滑动窗口：双指针维持窗口 + 哈希/计数维护窗口内状态，窗口不合法时收缩左端。
- 二分查找：明确找"精确 / 左边界 / 右边界"，循环条件与更新边界与目标对应，mid 用 (l + r) >>> 1 防溢出。
- BFS：队列 + 层标记，适合最短路径与连通块；DFS：递归或栈，适合连通性与搜索。
- DP：定义状态、写转移方程、确定初始化与遍历顺序，能滚动则滚动优化空间。
- 回溯：选-递-撤三步，画决策树；去重靠排序 + 同层相邻相同跳过。
